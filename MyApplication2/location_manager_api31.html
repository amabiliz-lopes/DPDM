Na prática

Peça ACCESS_FINE_LOCATION (ou coarse para aproximada) em tempo de execução. Verifique provider habilitado, trate SecurityException e remova atualizações no ciclo de vida apropriado.

Exemplo Java · atualizações

JAVA · API 31
// Manifest: ACCESS_FINE_LOCATION
// Após conceder a permissão em tempo de execução:
LocationManager lm = (LocationManager)
    getSystemService(LOCATION_SERVICE);

if (checkSelfPermission(Manifest.permission.ACCESS_FINE_LOCATION)
        == PackageManager.PERMISSION_GRANTED) {
    String provider = lm.isProviderEnabled(
            LocationManager.GPS_PROVIDER)
        ? LocationManager.GPS_PROVIDER
        : LocationManager.NETWORK_PROVIDER;

    lm.requestLocationUpdates(provider,
        2_000L,       // intervalo desejado: 2 s
        5f,           // deslocamento mínimo: 5 m
        location -> {
            double lat = location.getLatitude();
            double lon = location.getLongitude();
            float accuracy = location.getAccuracy();
            runOnUiThread(() -> status.setText(
                lat + ", " + lon + " ±" + accuracy + " m"));
        },
        Looper.getMainLooper());
}

// Em onStop() quando não precisar mais:
lm.removeUpdates(locationListener);
Exemplo didático: solicitar permissão antes; registrar LocationListener como campo para removê-lo depois. Confirme provider disponível antes de usá-lo.
